# My Portfolio (Beginner)

This is a beginner-friendly portfolio template built with HTML, CSS, and JavaScript.

It includes:

- A hero section
- About, Projects, Skills, and Contact sections
- Responsive layout and simple interactivity (nav toggle, smooth scroll, form demo)

How to run locally

- Open `index.html` in your browser.

Quick commands (PowerShell):

```powershell
# Open in default browser
ii .\index.html
```

Recommended: install the VS Code Live Server extension and click "Go Live" for auto-reload.

Deploying

- GitHub Pages: push the repo and enable Pages from the `main` branch.
- Netlify: drag & drop the project folder or connect your Git repository.

Contact form

The contact form in this template is a front-end demo and does not send messages to a server. It validates input and shows a simulated success message
